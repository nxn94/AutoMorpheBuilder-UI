About this UI

A static, no-build, no-server UI for editing AutoMorpheBuilder's two config files. Loads and validates against the same JSON schema the build pipeline uses, generates output that passes npm run validate:config, and stays under one screen of JavaScript.

How to use it

  1. On the Patches tab, click Load sample or upload your own patches.json.
  2. Tick the boxes for the patches you want enabled.
  3. Click Download patches.json and replace that file in your fork.
  4. Repeat for Config if you want to add/remove apps, change ABI preference, etc.
  5. Commit, push, and run Build Morphe-patched apps via workflow_dispatch.

What the validator checks

Implemented locally in assets/validate.js — mirrors the rules in schemas/config.schema.json and the cross-key checks in .github/scripts/validate-config.js:

  • patch_repos keys must match the Android package-id regex (^[a-z][a-z0-9_]*(\.[a-z][a-z0-9_]*)+$).
  • name must match ^[a-z0-9][a-z0-9-]*$.
  • repo and apkmirror_path must be owner/slug with no whitespace.
  • preferred_arch must be one of arm64-v8a, armeabi-v7a, x86, x86_64.
  • cli.branch must be main or dev.
  • pin_version and pin_patch_tag are optional; if present, they must match the documented patterns.
  • Cross-key: no two apps can share the same name (release tag collisions).

Limitations

  • The UI cannot commit back to GitHub in v1 — it downloads files you commit yourself. PR-back via the Contents API is on the roadmap.
  • The UI does not read patches-list.json from upstream patch repos. It edits whatever patches you currently have toggles for, plus lets you add/remove arbitrary new patches.
  • The UI runs entirely in your browser. No data leaves your machine unless you click Fetch.
